# Hynish Archive — public edition

The Panchsheel Hynish (Plot GH-08A, Sector-1, Greater Noida West) story from public records, to 4 November 2026.
Open the site: https://protbhai.github.io/hynish-archive/

Public records only: official letters and plans filed on UP RERA, court orders, Authority orders and minutes,
NPCL notices, association notices published online, news reports (attributed, not adopted) and property listings.
Records naming private residents are cited, not reproduced. Not legal advice. Dated, not live.
SHA256_MANIFEST.txt lists every file's hash; the offline ZIP is attached to the latest release.

## For AI readers

The same data is published as plain JSON under `api/v1/` (start with `api/v1/index.json`; guide in `llms.txt`).
`mcp/hynish-mcp.mjs` is a one-file MCP server (Node 18+, no dependencies) that serves it as eight read-only tools.
See `mcp/README.md`.
